# 실제 제품 표면과 기본 규격의 적합도 실험

2026-09-13. 사진 재구성 전체 목표는 미완료다. 이 변경은 자동 배치를 기본으로 바꾼 것이 아니라, 실제 표면을 기본 모형에 맞출 수 있는지 검증하는 개발 실험이다. 일반 분석기에 새 모델을 연결하거나 사용자에게 다운로드를 추가하지 않았다.

## 확인한 원인

[직전 표면 진단](reconstruction-object-surface-probe-20260913.md)에서 user-04 하부장 후보의 하단 중앙이 실제로는 바닥 픽셀이며, 하부장 중심을 뜻하지 않는 것을 확인했다. 이번에는 같은 cabinet 픽셀의 법선을 이용해 수평 자세 가설을 검사했다. sink 픽셀은 몸체의 상자 맞춤에서 제외했다.

실제 23,824개 입력 중 cabinet 몸체 20,909개, sink 부품 2,915개다. 두 수직 표면의 방향 차이는 직각에서 약 3.64° 벗어났고 관측된 두 면의 길이는 약 527mm와 1,855mm였다. 값은 모델이 추정한 좌표이며 실측 제품 규격이 아니다. 원사진에 픽셀을 재투영해 각각 끝판과 길게 이어진 옆면에 대응하는 것도 직접 확인했다.

현재 기본 규격 1,200×550×850mm를 그대로 검사하면 축 배정에 따라 몸체 점의 약 85.1% 또는 90.6%만 포함한다. 검사 허용값을 바꾸거나 사진 전용 규격으로 늘리지 않았고 모든 자세는 보류됐다. 따라서 이 사례는 중심·방향뿐 아니라 기본 규격 또는 모델 거리의 불일치도 함께 다뤄야 한다. 어느 쪽이 실제 치수와 다른지는 사진 한 장의 현재 자료로 확정하지 않는다.

## 구현과 계약

- `src/lib/reconstruction/observed-product-pose.ts`의 `proposeObservedProductPose`는 같은 사진의 모델 좌표·법선·종류 라벨·관측 벽을 받는 순수 실험 함수다. 일반 후보·저장·렌더 경로를 수정하지 않는다.
- 사각 범위 안의 모든 픽셀을 몸체로 사용하지 않는다. cabinet 라벨의 수직 표면을 별도로 검사하고, 같은 법선 방향이어도 서로 다른 거리로 갈라진 표면은 한 면으로 취급하지 않는다.
- 규격은 사용자·상품·기본값의 출처를 그대로 유지한다. 정해진 규격은 자동 축소·확대하지 않고, 알 수 없는 규격은 관측 범위와 축만 남긴다.
- 수직 중심과 가려진 제품 외곽은 생성하지 않는다. 별도의 정면 또는 뒤벽 연결 근거가 없으면 앞뒤 양쪽 가설을 구분할 수 없다고 기록한다. 가까운 벽이나 큰 면을 제품 뒤쪽/앞쪽이라고 확정하지 않는다.
- 단일 면, 비직각 면, 반사·혼입 미확인, 규격 불일치, 벽 침범, 불일치한 사진 해시는 보류 사유다. `proposed`여도 자동 적용이나 실측 완료를 뜻하지 않는다.

검사 임계값은 합성 회귀와 현재 개발 자료를 위한 실험값이며 인식 신뢰도나 실제 제품 정확도가 검증된 값이 아니다. 앞으로 추정 규격 제안을 추가할 때도 실측과 구분하고, 미관측 면을 만들어 낸 부분과 기본값을 표시해야 한다.

## 실제 재생과 비교 그림

`tests/reconstruction-product-pose-inputs.py`는 이미 실행한 DeepLab 라벨·MoGe 점군·실제 Qwen 관측·카메라 결과를 읽는다. 원본 사진, 카메라 보고서, 점군과 각 소스의 해시를 보존한다. 공간 치수도 실제 저장된 각 실행 설정을 사용한다. 새 모델 추론·다운로드·사진 외부 전송·사용자 위치 보정은 없다.

`tests/reconstruction-product-pose-replay.ts`는 이 자료를 현재 후보 파이프라인과 새 검사에서 재생한다. user-02/03의 카메라가 보류 상태라 모델 좌표를 방 좌표로 바꾸지 않는다. 이 작은 검사는 사각 하부장만 지원하므로 다른 종류는 명시적으로 범위 밖으로 기록한다. 네 사진 전체를 지원하거나 자동 배치가 개선됐다고 집계하지 않는다.

실제 결과 경로:

- `test-results/reconstruction-product-pose-20260913/inputs/`: 사진별 입력과 기존 실제 실행 출처
- `results/`: 현재 코드 해시, 기본 규격, 보류 이유, 시간, 원래 배치와의 비교
- `plots/user-04-item_04.png`: 원본의 관측 표면, 위에서 본 점군·방 경계, 기존 잘못된 모형 상자의 원사진 재투영

그림은 진단용이다. 원본 사진을 최종 표준 공간의 제품 표면으로 붙이지 않는다. 표시용 점만 일정 간격으로 줄였고 수치 계산은 전체 입력을 사용한다. 자동 적용한 새 자세는 0개다. 기존 기하 후보 파이프라인 배치는 user-01/02/03이 0개, user-04가 3개이며 이번 실험의 성공률로 사용하지 않는다.
