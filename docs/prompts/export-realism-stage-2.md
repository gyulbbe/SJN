## 4. 2-1 편집 화면 설비 그림자

- 1-2의 내보내기 그림자 보정을 **실시간 렌더와 시안 미리보기에도** 적용한다. 방법은 코드를 보고 정한다.
  - 후보: 그림자만 담당하는 별도 광원(원뿔을 좁히거나 다른 광원 형식)
  - 후보: 그림자 카메라를 직접 설정하는 방식
  - 내보내기와 실시간이 **같은 그림자 규칙**을 쓰게 정리한다. 두 경로에 따로 된 보정이 남지 않게 한다.
- 실시간 그림자는 겹쳐 찍기 없이 한 장이다.
  - 그림자 맵 크기와 PCF 반경을 조정해 부드러운 경계를 낸다.
  - 내보내기의 부드러운 그림자와 크게 달라 보이지 않게 맞춘다.
- **의도된 기준선 변경**
  - 편집 화면·시안 미리보기의 픽셀이 바뀌는 것은 이번 작업의 목적이다.
  - 바뀐 기준선을 새로 저장하고, 변경 전후 비교 이미지를 남긴다.
  - 그림자 외의 영역(타일 색, 설비 모양, 방 밖 배경)은 바뀌지 않았는지 영역별로 확인한다.
- **시안 미리보기 캐시**: 저장된 미리보기(IndexedDB 등)가 그림자 없는 옛 이미지로 남지 않게 한다. 캐시 키나 렌더러 버전을 올리는 방식을 확인하고 적용한다.
- **성능**: Iris Xe(D3D11 기본값, 전원 연결 상태 기록)에서 편집 화면 프레임 시간을 변경 전후로 잰다. 그림자 맵 갱신을 매 프레임 하는지, 장면이 바뀔 때만 하는지도 정한다. SwiftShader 수치도 기록한다.
- **2D 합성 경로**(벽 구조 없는 프로젝트)는 자체 그림자 규칙이 있다. 바꾸지 않는다.
- **판단 기준**
  - 편집 화면에서 변기·세면대·욕조 아래 그림자가 보인다. 1단계 측정처럼 바닥 그림자 대비와 경계 폭으로 수치화한다.
  - 그림자 외 영역은 변경 전과 같다(ΔE2000 ≤ 0.5, 또는 픽셀 차 0).
  - Iris Xe 편집 화면 프레임 시간 증가가 작다. 목표 +2ms 이내, 넘으면 근거와 함께 보고한다.
  - 자원 반복 해제 시 증가가 없다.
  - FLUX 입력 설비 상자(`fixtureBounds`)가 그대로 맞는다.

## 5. 2-2 저사양 기기 내보내기

- GPU가 약한 기기에서 겹쳐 찍기 동안 **화면이 1초 넘게 멈추지 않게** 한다. 취소는 1초 안에 반영되게 한다.
  - 후보: 한 장을 가로 띠·타일 단위로 나눠 그리며 사이사이 양보하기, 첫 장 시간으로 내부 해상도나 장 수 조정하기
  - 결과 이미지 크기는 사용자가 고른 그대로 둔다.
- **장 수가 적을 때 점무늬**: 화면 좌표 디더링 때문에 생긴다. 적은 장 수에서도 경계가 매끈한 그림자 방식(필터나 그림자 맵 설정)을 찾아 적용한다. 32장 결과(기본값)는 1단계와 눈으로 구분되지 않아야 한다.
- 진행률(%)과 "다운로드 취소" 버튼 동작은 1단계 그대로 유지한다.
- **판단 기준**(SwiftShader 1024·2048·4096에서 측정)
  - 메인 스레드 최장 막힘 ≤ 1초(Long Tasks API)
  - 취소 후 1초 안에 멈추고 자원이 해제된다.
  - 1~4장 결과에 눈에 띄는 점무늬가 없다. 그림자 경계 영역의 노이즈 지표를 정해 이전과 비교한다.
  - Iris Xe D3D11 32장 시간이 1단계보다 크게 늘지 않는다(±20% 안).

## 6. 2-3 기존 화면 테스트 실패 정리

- 실패 3개가 **테스트가 옛 화면 구조를 찾는 문제**인지, **실제 모바일 화면 문제**인지 먼저 가린다.
  - "공간 크기"와 "내보내기"가 더보기 메뉴 안으로 옮겨져 사용자가 여전히 찾을 수 있으면, 테스트를 새 구조에 맞게 고친다.
  - 실제로 기능에 닿을 수 없으면 화면을 고친다. 고치기 전에 무엇이 문제인지 보고 문서에 적는다.
- **판단 기준**: e2e 전체가 실패 0으로 통과한다(건너뜀은 이유 기록).

## 7. 반드시 지킬 조건

- 이번 작업에서 픽셀이 바뀌어도 되는 곳은 **편집 화면·시안 미리보기의 설비 그림자**뿐이다. 나머지는 다음을 지킨다.
  - 2D 합성 출력, 타일 색, 견적·수량·저장 값은 그대로다.
  - 내보내기 결과는 판단 기준 안이다.
- 렌더러 자원 해제 규칙을 지킨다(`ViewerLightingLut`, 컨텍스트 손실, 취소 중 해제).
- 시스템 설정과 Chrome 전역 플래그는 바꾸지 않는다. 측정은 테스트 브라우저 옵션으로만 하고, 기본 백엔드 D3D11에서 먼저 잰다.
- Tailwind를 우선 쓴다. `globals.css`의 `p{margin:0}` 때문에 여백이 필요한 표시 요소는 `<div>`로 만든다.
- 줄바꿈은 작업 사본 CRLF, 저장소 LF다. Prettier는 쓰기에 `--end-of-line crlf --write`, 검사에 `--end-of-line auto`를 쓴다. typecheck 뒤 `next-env.d.ts`를 되돌린다.
