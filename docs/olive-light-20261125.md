# 올리브 벽 밝기 (2026-11-25, 결과: 지금 방식의 벽·바닥 밝기 허용 폭 0)

- 문제(백로그 4번, 열린 문제 4번 남은 것): 지금 방식 최종 그림에서 올리브 유광 벽돌 벽이 설계보다 조금 밝다(L\* 약 +9).
- 원인: 다듬기의 색 단계(`color.ts` `lightnessReturn`)가 면 평균 밝기 차이 ±8(`LIGHTNESS_BAND`)을 "사진의 빛"으로 그대로 두고, 그 밖의 90%(`LIGHTNESS_RETURN`)만 되돌린다.
  - AI는 올리브 벽을 설계보다 11~25 밝게 그린다. 그러면 약 +9가 남는다.
- 결론: 지금 방식 다듬기의 벽·바닥은 허용 폭 없이(`current-refine.ts` `FACE_LIGHTNESS_BAND` 0) 모든 밝기 변화의 90%를 되돌린다.
  - 도기 밝기 규칙(`fixture-light.ts`)과 다른 방식(빈 방 합성 A·B·C)은 `LIGHTNESS_BAND` 8 그대로다.
- AI에 보내는 그림·문장·호출 수는 그대로다. AI 답을 받은 뒤의 다듬기만 바뀐다.
- 감독(Codex)의 가린 평가와 개발 세션 측정이다.

  - 이번 항목은 AI에 보내는 것을 바꾸지 않으므로 이 답으로 앱 최종을 그대로 재현할 수 있다.

## 3. 숫자 (최종 면 평균 L\* − 설계)

### 앱이 직접 잰 값 (색 단계 뒤, AI 그림 이동 dx·dy 반영, 면 가장자리 안쪽)

|                              | 폭 8(이전)                      | 폭 0(지금)          |
| ---------------------------- | ------------------------------- | ------------------- |
| 올리브 벽, Cloudflare        | 약 +9 (변화 11~25에서 8을 남김) | **+1.6** (최대 2.5) |
| 올리브 벽, 로컬              | 약 +9                           | **+1.2** (최대 1.8) |
| 회색 바닥, Cloudflare / 로컬 |                                 | +1.0 / +0.7         |

- 남는 +1.2~+1.6은 되돌리지 않는 10%(`LIGHTNESS_RETURN` 0.9) 몫이다.
- 색 단계 뒤의 단계(도기 밝기·몸통 등)는 벽 밝기를 바꾸지 않는다.

### 설계 마스크 그대로 잰 값 (34단계 비교용)

- 이 방식은 AI 그림이 4~12px 옮겨진 것을 따라가지 않는다. 그래서 줄눈·가장자리·이웃 면이 섞이고, 정면 장면의 한 벽은 +9가 나온다.
- 34단계에 적은 "폭 0에서도 +4 남음"은 **이 측정 오차**였다(35단계에서 앱이 잰 값으로 확인).
- 세 후보를 같은 방식으로 재서 비교 순서는 그대로다.

| 면                           | 지금          | 폭 4        | 폭 0        |
| ---------------------------- | ------------- | ----------- | ----------- |
| 올리브 벽, Cloudflare / 로컬 | +11.3 / +10.1 | +7.9 / +7.4 | +4.6 / +4.1 |
| 회색 바닥, Cloudflare / 로컬 | +8.0 / +9.7   | +5.3 / +7.1 | +1.8 / +4.4 |
| 검정 벽(로컬)                | +3.3          | +3.5        | +4.4        |
| 베이지 벽(로컬)              | +0.5          | +1.1        | +1.9        |
| 흰 벽(로컬)                  | −3.6          | −2.7        | −0.1        |

- 흰 벽은 설계 L\* 약 90이다. 그래서 폭 0에서 L\* 92 위 비율이 16.6 → 39.1%로 오른다.
  - 감독은 흰 타일 무늬·모서리 그늘이 남는다고 봤다.
- 욕조 앞면 얼룩, 제품, 줄눈 위치는 바뀌지 않는다(이 규칙은 벽·바닥 면 평균 밝기만 옮긴다).

## 5. 남은 것

- 올리브 벽은 최종에서 설계보다 +1.2~+1.6 밝다. `LIGHTNESS_RETURN`을 1로 하면 없어지지만, 눈에 띄는 크기보다 작아 바꾸지 않았다.
- AI 원본의 올리브 회색화는 그대로다([올리브 벽 이름](olive-name-20261125.md)).
