# 젠다이: 붙인 젠다이를 하나로 그리기, 옆에 이어 만들기 — 결과 (2026-11-11~12)

젠다이 두 개를 붙이면 하나로 이어져 보이고, 옆에 새로 만들 때 붙는 위치·높이·깊이가 저절로 맞는다. AI 변환에서 젠다이 모양을 지키는 일은 따로 시험한다(이 문서 범위 밖).

## 3. 구분선의 원인과 고친 것

| 원인 | 확인 | 고친 것 |
| --- | --- | --- |
| 맞닿은 안쪽 면과 틈 사이로 보이는 벽 | 1mm 띄운 두 개의 다운로드에 세로선이 보임 | 이웃이 덮은 면은 조각으로 내지 않음. 5mm 이하 틈은 닫아서 그림 |
| 바닥 접촉 음영이 겹침 | 음영이 상자마다 곱해져 이음매 앞 바닥이 두 번 어두워짐 | 맞닿은 젠다이는 한 덩어리로 계산(가장 가까운 상자 하나만) |
| 면 음영의 경계 | 안쪽 면이 없어지면 남지 않음 | 따로 고칠 것 없음 |
| 그림자 맵 | 이어진 덩어리가 닫힌 모양이라 이음매에 그림자 경계가 없음 | 따로 고칠 것 없음 |
| 윗면 타일 방향 | 같은 벽은 벽 좌표로 이어짐. ㄱ자는 벽마다 방향이 다름 | ㄱ자는 맞댄 이음선 하나만 남김(사용자 결정) |

이음매를 가로지르는 이웃 픽셀의 밝기 차(줄눈 없는 면, 0~255):

| | 앞면 | 윗면 |
| --- | --- | --- |
| 편집 화면 | 0.33 | 0.33 |
| 다운로드(32장 + 사진 효과) | 2 | 1 |
| AI 캡처 | 0.33 | 0.67 |

- 맞닿음, 1mm 틈, 5mm 틈 모두 같은 값이다. 다운로드의 2는 사진 효과의 입자다. 시험 기준은 3 이하다.
- 이음매 앞 바닥 밝기는 97.7, 옆은 96.5다(차 3 이하).

## 4. 바뀐 규칙

- **검증(`validateWallFeatures`):** 젠다이끼리는 맞닿아도 된다(같은 벽 옆·위아래, 다른 벽 ㄱ자). 부피가 세 축 모두 1e-6mm 넘게 겹치면 거절한다. 메시지는 "젠다이끼리는 맞닿게 놓을 수 있지만 겹칠 수는 없어요."다.
- 젠다이와 홈, 홈과 홈은 지금처럼 맞닿는 것도 거절한다.
- **이어진 모양(`joinedLedges`):** 그리기·면적·바닥 접촉 음영이 함께 쓴다.
  - 마주 보는 두 젠다이의 틈이 5mm 이하면 목록에서 뒤에 있는 쪽을 늘려 틈을 닫는다. 저장값은 바꾸지 않는다.
  - 모서리에서는 끝이 틈을 향한 쪽이 늘어난다. 깊이는 바뀌지 않는다.
  - 늘린 결과가 다른 구조와 겹치면 그 틈은 닫지 않는다. 모서리나 변끼리만 만나는 것도 닫지 않는다.
  - 반올림 오차만큼 다른 끝은 같은 숫자로 맞춘다.
- **ㄱ자:** 옆벽 젠다이의 끝이 뒷벽 젠다이의 앞면에 닿는 배치다(반대도 됨). 모서리 칸은 한쪽만 차지한다.
- **3D 조각:** 이웃이 덮은 면은 빼고 남은 부분만 낸다.
  - 같은 벽의 이웃이 덮은 부분은 내지 않는다.
  - 다른 벽의 이웃이 덮은 부분은 그 벽이 숨겨졌을 때만 보인다(`againstFace`). ㄱ자의 한쪽 벽이 숨으면 남은 쪽의 맞닿았던 면이 다시 보인다.
  - 높이가 다르면 높은 쪽 옆면 가운데 위로 나온 부분만 남는다.
- **렌더 버전:** `room-view-v13-ledge-join`. 5mm 이하로 띄운 예전 장면의 그림이 바뀌기 때문이다. 2D 시안 미리보기(`DESIGN_RENDER_REVISION` 4)는 벽 구조를 그리지 않아 그대로다.
- 저장 형식, D1 스키마, API 경로는 그대로다.

## 5. 면적

맞닿아 가려진 면은 양쪽에서 한 번씩 뺀다. 2.4m 방, 깊이 200mm 기준 예:

| 배치 | 벽 타일 변화 |
| --- | --- |
| 옆으로 이은 두 개(폭 800 + 700, 높이 900) | 폭 1,500 하나와 같음 |
| 1mm 띄워 놓은 같은 두 개 | 폭 1,501 하나와 같음(뒤쪽이 1mm 늘어남) |
| 6mm 띄운 두 개 | 폭 1,500 하나 + 옆면 2개(0.36㎡) |
| 계단(높이 900 옆에 600) | 따로 계산한 합 − 2 × 0.6 × 0.2㎡ |
| 위아래(깊이 200 위에 120) | 따로 계산한 합 − 2 × 폭 × 0.12 |
| ㄱ자(깊이 100, 높이 1,000) | 뒷벽·왼벽 각각 맞닿은 0.1㎡를 뺌 |

- 식으로 낸 면적이 3D 조각(숨는 조각 제외) 넓이의 합과 같은지 시험한다.

## 6. 이어 만들기 쓰는 법

1. **벽 구조 → 젠다이**를 켠다.
2. 이미 있는 젠다이 옆(끝에서 50mm 안)에서 끌면 끝이 딱 붙고, 깊이와 바닥에서 높이가 이웃과 같아진다. 그린 윗면이 이웃 윗면에서 100mm 안이면 높이도 같아진다.
3. 높이를 100mm 넘게 다르게 그리면 붙기만 하고 높이는 그린 대로 남는다(계단).
4. 옆 벽으로 꺾으려면 그 벽을 모서리 끝까지(또는 넘어서) 끈다. 모서리에 서 있는 젠다이의 앞면에서 끝난다.
5. 젠다이 위나 바로 옆을 누르면 누른 쪽 옆에 새 젠다이가 선다. 높이와 바닥에서 높이는 마지막에 적용한 젠다이의 값이다.
6. 놓인 젠다이를 끌어 옮길 때도 50mm 안이면 붙는다. 크기는 그대로다.
7. 떠 있는 젠다이를 다른 젠다이 윗면 50mm 안에 놓으면 그 위에 얹힌다.

- 맞춰지면 주황 점선 안내선이 보이고, 도구줄에 "옆 젠다이에 맞췄어요 · 높이 1000 · 깊이 100"처럼 나온다.
- 카드의 숫자를 고치면 맞춤에서 벗어날 수 있다.

## 8. 옛 화면

- 배포 전에 열어 둔 탭(옛 코드)이 새 규칙으로 저장된 맞닿은 젠다이 프로젝트를 열면, 옛 검증이 "서로 겹치거나 맞닿는 벽 구조는…"으로 거절해 열리지 않는다. 저장은 일어나지 않아 자료는 그대로다. 새로고침하면 새 코드로 열린다.
- 이것은 코드로 확인한 것이고, 옛 탭으로 직접 해 보지는 않았다.
- 렌더 버전이 바뀌어 프로젝트 목록의 저장된 요약(미리보기 정보)이 한 번 다시 만들어진다. 지난 렌더 변경(v10~v12) 때와 같다.

## 11. 한계

- 편집 화면 그림 밖(바깥 여백)에서 손을 떼면 그리던 것이 취소된다. 전부터 그랬다. 옆 벽으로 꺾을 때 모서리를 넘겨 끌더라도 그림 안에서 떼야 한다.
- 모서리에 서 있지 않은 옆벽 젠다이(끝이 모서리에서 떨어진 것)에는 꺾어 붙지 않는다.
- 이웃의 높이는 100mm 안일 때만 따라간다. 그보다 다르게 그린 뒤 같게 하려면 카드에서 숫자를 고친다.
- 붙기를 끄는 버튼은 없다. 일부러 띄우려면 카드에서 숫자를 고친다(5mm 이하 틈은 이어서 그려진다).
- ㄱ자 윗면은 맞댄 이음이라 벽마다 타일 방향이 다르고 이음선이 하나 보인다.
- 젠다이와 홈은 여전히 맞닿을 수 없다. 젠다이 안에 홈 내기, 상판 자재 따로 고르기, 끌어서 크기 바꾸기는 없다.
