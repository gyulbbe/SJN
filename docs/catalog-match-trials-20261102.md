# 사진에서 비슷한 자재 찾기: 방법 시험 결과 (2026-11-02~)

"사진으로 비교 공간 만들기"를 사진 복원 대신 **등록된 타일·제품 중 가장 비슷한 것을 비슷한 위치에 놓는** 방식으로 바꾸기 전에, 여러 방법을 같은 자료·같은 기준으로 시험한 기록이다. 앱 코드·저장 형식·DB·API·배포는 바꾸지 않았다. 시험 도구는 [tests/catalog-match](../tests/catalog-match/), 결과 자료는 git에서 제외된 `C:\dev\SJN\test-results\catalog-match\`에 있다.

## 2. 명세와 달랐던 것

- `.dev.vars`에 `AI_EXTRA_1_*`가 없다(있는 이름: APP_ENV, STORAGE_MODE, BETTER_AUTH_*, GOOGLE_*, CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_ANALYTICS_TOKEN). 시험 AI 호출은 로컬 임시 Worker의 `AI` 바인딩(이 PC의 wrangler 로그인 계정)으로 한다. 선례는 [flux-product-refine](../tests/flux-product-refine/)이다.
- 저장된 Gemma 답은 15장에만 있다. 공개 36장의 저장 결과(`test-results/reconstruction-corpus-final/bath-XX/`)는 `baseline.json`(DeepLab 면·후보·`tile` 값, 2026-09-13 코드)과 `candidate.json`(로컬 Qwen)이다. 개발 24장의 Gemma 상자는 새로 부른다. `bath-01`에는 `candidate.json`이 없다.
- 명세대로인 것: 15장 실행의 요청 수(사진당 4~10, 평균 약 6.8), 세면대가 있는 사진 12장, `placeLayout` 197행(붙여 등록한 제품 유지)·211행(같은 방·장애물 없음이면 자리 검사 생략), Gemma `bbox_2d` 순서, onnxruntime-web 1.29.0(Transformers.js 없음), 로컬 DB(변기 13, 세면대 6, 욕조 5, 타일 2), Clef 입력 형식.
- 명세가 "넣지 않는다"고 한 로컬 FLUX는 사용자 결정으로 자원에 들어갔다(매칭 후보는 아님).

## 3. 탈락 기준 (라운드를 돌리기 전에 적음)

결과를 본 뒤 낮추지 않는다. 바꿔야 하면 이유를 적고 사용자에게 묻는다.

- **R1 타일(AI 없음):** 합성 개발 50의 같은 무늬 기준 상위 5 적중이 1등보다 10점 넘게 낮으면 탈락. 1,923개 비교가 CPU 4배 감속에서 2분을 넘으면 탈락. 최대 3개까지 남긴다. 조각 변형(자동·깨끗한 사각형, 곧게 펴기, 조명 걷어내기, 반복 그리기)은 수치와 DINOv2의 합성 개발 50 결과로 고정한다.
- **R2 위치(AI 없음):** 개발 24장에서 같은 벽 비율이 기준선(사진 좌우 순서로 뒤 벽에 나열)보다 10점 이상 높지 않으면 단독 후보에서 뺀다. 결합 재료로는 쓸 수 있다.
- **R3 AI 소량 확인:** 형식 오류가 2회 이상이거나, 본 시험의 작업을 다 했을 때 사진 1장 예상 비용이 100뉴런을 넘으면 탈락. 약관 동의를 요구하면 보류하고 사용자에게 묻는다. 남기는 모델은 최대 2개.
- **R4 AI 본 시험:** 후보판 고르기는 같은 후보를 순서만 바꿔 3번 물었을 때 답이 유지된 사진이 5장 중 4장 미만이면 탈락. 수치 방법 1등보다 낫다는 근거(합성 개발의 같은 무늬 상위 1, 또는 사람 평가)가 없으면 비용 때문에 뺀다.
- **제품 "맞는 게 없음":** 흰 변기를 잘못 거른 비율이 20%를 넘는 기준값은 탈락.
- **추천 조건:** 사진 1장 100뉴런 이하, 새 다운로드 150MB 이하, GPU 없는 PC(CPU 4배 감속으로 대신) 2분 이내. 이 안에서 정확도 1등을 고른다.
- **사람 평가:** 위치 정답지 확인·전체 1~5점을 합쳐 20분 이내. 항목 수 × 약 3초로 미리 계산하고 넘으면 앞 라운드에서 방법을 줄인다.
- **최종 평가 12장:** 조합이 정해지기 전에 결과를 열지 않고, 고른 조합 그대로 1회 돌린다. 여기서 조정하지 않는다.
