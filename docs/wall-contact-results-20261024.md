# 벽에 설치한 제품은 항상 벽에 붙게 결과 (2026-10-24)

**사용자 보고:** `test-results/wall-contact/user-report/shower-floating.webp`
- 기본 방 정면 보기의 2D 편집 화면이다.
- 샤워 설비(수전 + 핸드 샤워)를 **오른쪽 벽**에 놓았다. 사진은 정면 사진 한 장이고, 좌우 투명 여백이 커서 보이는 폭이 그림의 약 30%다.
- 샤워가 오른쪽 벽 가까이에서 뒷벽 앞 공중에 떠 보였다.

**사용자 요구**
- 벽에 설치한 제품은 스위치 없이 항상 벽에 붙는다.
- "벽에 붙이기"는 바닥 제품만의 옵션이다.

## 2. 측정 (고치기 전)
- **방법:** `tests/wall-contact-measure.test.ts`(`SJN_WALL_MEASURE=1`, 결과 `test-results/wall-contact/measure.json`, 도우미 `tests/helpers/wall-contact.ts`)

  - 3D: `buildViewerFixtures`, 네 방향 카메라
  - 2D: 편집기가 열 때 그리는 그림(`reprojectRoomScene`)을 방 좌표로 되돌린다.
- **제품**
  - 합성 샤워: 사용자 사진과 같은 여백, 330×1000×150. 정면만(기준점 가운데 / 슬라이드 바) / 네 방향
  - 로컬 벽걸이 세면대: 560×560×440, 실제 사진 경계, 정면만 / 네 방향
  - 여백이 거의 없는 거울
  - 표준 모형: shower, mirror, mirrorCabinet, wallShelf, wallCabinet, basin
  - 샤워 커튼은 바닥 틀이라 뺐다.
- **로컬 데이터(읽기만):** 프로젝트 16개
  - 벽 제품은 왼쪽 벽의 벽걸이 세면대뿐이다(사진 9, 표준 모형 2).
  - 설치 방식과 놓인 면이 다른 제품은 0개다.

**원인**
1. **2D 옆벽 제품이 화면을 보는 카드였다**(`projectRoomFixture`). 보고 화면의 원인이다.
   - 기준점을 벽 위 점에 두고 사진을 화면과 나란하게 그렸다.
   - 정면 사진은 벽에서 방 안으로 제품 가로만큼 튀어나온 판처럼 보였다.
   - 기준점이 가운데면 제품 절반이 벽 속에 그려졌다.
   - 보고 화면은 기준점이 슬라이드 바(오른쪽)라 벽 쪽 끝이 벽 선에 거의 닿고, 나머지가 324mm 방 안으로 나왔다.
2. **3D 벽 맞춤이 투명 여백을 포함한 사진 사각형 기준이었다**(`seatProduct`).
   - 판이 벽과 수직인 보기에서 보이는 제품이 여백만큼 떴다(샤워 406mm, 세면대 109~141mm).
   - 옆벽 제품의 정면·뒤 보기는 간격이 0이었다(`gapAt`).
3. **정면 사진만 있는 제품은 판이 카메라를 따라 돌아서**, 옆에서 보면 벽에서 제품 가로만큼 튀어나온 판이 됐다(먼 끝 606~838mm).
4. **그림자:** 2D "접지 그림자"는 기준점 아래의 바닥용 타원이라 벽 위에 얼룩으로 남았다. 3D는 사진판이 벽에서 1mm라 천장 조명 그림자가 사진 뒤에 숨었다. 보고 스크린샷에는 그림자가 없었다(벽 밝기 측정).
5. **표준 모형은 문제없었다.** 틀이 상자로 맞춰지고, 벽 면은 원점에서 깊이의 절반만큼 방 안에 놓인다(`reconstructionModelTransform`).
6. **`againstWall` 남음:** 바닥 제품을 벽으로 옮길 때 지우지 않았다(`setFace`). 그리기에는 무시됐지만 저장됐다.

## 3. 바꾼 규칙
벽 면(left·back·right)의 사진 제품은 설치 방식과 상관없이 놓인 면으로 정한다.

- **정면·뒤 사진(제품의 얼굴과 등):** 벽면과 나란히 벽 1mm 앞에 붙는다([room-fixtures.ts](../src/lib/room-fixtures.ts) `liesOnWall`).
  - 3D: 판은 카메라를 따라 돌지 않는다. 앞면은 카메라 쪽 벽 면을 봐서(벽 뒤에서 보면 뒤집음) 글씨가 거꾸로 보이지 않는다(`wallFacing`).
  - 2D: 옆벽에서는 벽면 위 원근 사각형(`projectedQuad`)으로 그린다. 옛 평면 표준 모형과 같은 방식이고, 컴포지터·선택 다각형·AI 내보내기 상자가 이미 이 필드를 지원한다. 저장 필드를 새로 만들지 않았다.
  - 뒷벽에서는 카메라를 보는 그림과 벽면 그림이 같다(z = 1mm).
- **왼쪽·오른쪽 사진(옆모습):** 카메라를 보는 카드다. **보이는** 벽 쪽 끝(투명 여백이 아님)을 벽 1mm 앞에 둔다.
  - 3D `seatProduct`: 사각형 대신 보이는 영역의 네 모서리(`contentCorners`)로 맞춘다.
  - 2D: 바닥 벽 붙이기와 같은 식으로 그린다(`wallDrawnAt`).
- 높이와 벽을 따라가는 위치는 사용자 u/v 그대로다. 벽과 나란한 그림은 기준점이 그 점에 온다(2D와 3D가 같음).
- 간격은 모든 방향에서 1mm다. 클릭이 벽이 아닌 제품을 고른다.
- 어느 방향에서 어떤 사진을 쓸지는 그대로다(`choosePhotoForView`). 그래서 2D와 3D 정면 보기가 같은 사진이다.
- **2D 되읽기:** 끌기에서 u/v를 되돌릴 때 그 그림이 놓인 벽 축 좌표에서 읽는다(`roomPositionFromPhoto`의 `across`). 끌어도 높이·가로 위치가 밀리지 않는다.
- **자재를 아직 못 읽었을 때:** 벽면 사각형으로 그려진 제품은 마지막 그림을 그대로 둔다. 자재가 오면 `reprojectRoomScene`이 다시 그린다.
- **방 밖 알림:** 3D "제품이 방 밖으로 나가요"는 투명 여백이 아니라 보이는 영역으로 판단한다.
- **방향 안내 문구:** 벽 위 정면 사진은 "벽에 붙어 정면 보기에서 비스듬히 보여요."다. 뒤 사진은 "벽에 붙어 제품의 뒤가 보여요."다. 옆벽에는 여전히 옆모습 사진이 더 어울린다고 알리고, 맞는 사진이 있으면 바꾸기 버튼을 둔다.

### 고친 뒤
`tests/wall-contact.test.ts`가 고정한다.

| 경우 | 2D | 3D 네 방향 |
| --- | --- | --- |
| 정면·뒤 사진(세 벽) | 1 / 1(옆벽 벽면 사각형), 뒷벽 0~1 | 1 / 1 |
| 옆모습 사진 | 1 / 제품 깊이(샤워 154, 세면대 431) | 1 / 제품 깊이 |
| 표준 모형 | 3D와 같음 | 0 / 깊이(그대로) |

- 2D 벽면 사각형의 네 모서리와 3D 정면 보기의 사진판 네 모서리가 같다(소수 넷째 자리).

### 그림자 (c)
- **2D**([compositor.ts](../src/lib/render/compositor.ts) `wallShadow`): 벽 사진 제품은 바닥용 타원 대신 **자기 윤곽**을 저장된 그림자 위치만큼 옮기고 흐리게 그린다(13점).
  - 저장된 `fixture.shadow`의 진하기·부드러움·가로·세로 위치를 그대로 쓴다. 그림자 너비는 쓰지 않아 속성 패널에서 숨겼다. 제목은 "벽 그림자"다.
- **3D**(`wallShadow`, `softOutline`): 벽과 나란한 사진판 뒤(벽 0.5mm 앞)에 윤곽을 작게 흐린 검은 판을 15mm 아래로 둔다.
  - 진하기는 `fixture.shadow.opacity`다. 0이면 그리지 않는다. 위치·부드러움은 고정이다.
  - 벽 뒤에서 보는 화면(벽이 잘려 보임)에서는 숨긴다.
  - 크기·자리·방 밖 판정에 넣지 않는다.
  - 3D 안내 "정면 사진의 접지 그림자는 회전하지 않으며…"는 바닥 제품에만 낸다.

## 4. 속성 패널과 저장값
- **벽 면 제품:** 스위치 대신 "벽에 설치한 제품은 항상 벽에 붙어요." 한 줄이다([wall-contact-switch.tsx](../src/components/editor/wall-contact-switch.tsx) `WallInstallNote`).
- **바닥 면 제품:** "벽에 붙이기" 스위치 그대로다.
- **`againstWall` 정리**
  - 면을 벽으로 바꿀 때 지운다(`setFace`).
  - 모든 편집에서 바닥이 아니면 지운다(`normalizeRoomScene`). 그래서 다음 저장 때 사라진다.
- **설치 방식과 놓인 면이 다를 때(Q2)**
  - 조건: 설치 방식이 벽걸이형·매립형·천장형인데 바닥 면에 있거나, 바닥형인데 벽 면에 있을 때
  - "설치 방식과 놓인 곳이 달라요. 이 제품은 벽걸이형이에요."와 [벽으로 옮기기](뒷벽) 또는 [바닥으로 옮기기] 버튼을 보인다.
  - 버튼은 속성 패널의 설치 면 바꾸기와 같다. 맞는 사진도 함께 바뀌고, 실행 취소 한 번이다.
  - 자동으로 옮기지 않는다.

## 5. 렌더 버전
- 기존 프로젝트의 그림이 바뀐다(옆벽 제품, 옆 보기, 벽과 나란한 정면 사진, 벽 그림자).
- 그래서 `room-view-v10-product-size`를 **`room-view-v11-wall-contact`**로 올렸다. 시안 미리보기·프로젝트 요약 캐시 키가 따라 바뀐다.
- 2D 편집 화면의 기존 프로젝트는 열 때 다시 그리는 읽기 이전(`reprojectRoomScene`)이 새 그림을 그리고, 다음 편집 때 저장된다. u/v는 바뀌지 않는다.

## 6. 한계
- 옆벽의 정면 사진은 정면 보기에서 좁게 보인다(사용자 선택). 옆모습 사진을 등록하면 정면 보기에서 옆모습이 보인다.
- 2D에서 벽면 사각형으로 그린 제품은 선택 테두리가 사각형 다각형이고, 크기 손잡이가 없다. 크기는 속성 패널 배율로 바꾼다(옛 평면 표준 모형과 같음).
- 공간 둘러보기에서 벽 뒤 화면은 그 벽이 잘려 보여서, 그 벽의 제품이 공중에 보인다(전과 같음).
- 벽면 사각형은 면 안 회전을 사각형에 그대로 넣는다. 3D 판도 자기 면 안에서 돈다.
