- 작업 줄기: `task/editor-glare`(SJN-dev, main `e86f980`에서)
- 앱 커밋: `62bf25b`. 시험·도구 커밋: `8f37f7a`, 문서는 이 문서와 함께 올린다.
- AI 호출: 없음. Cloudflare 0회, 로컬 FLUX 0회. 3D 그림만 그렸다.
- 까닭:
  - 사용자 질문(11-21): "앱 그림에도 상단에 빛이 비치는 거야 왜?"
  - AI 결과에서는 11-21부터 다듬기가 이 점을 뺀다([유광 벽 반사](wall-glare-20261121.md)).
  - 그 문서 7장에서 사용자는 편집 화면 3D의 유광 전체를 거칠게 하는 안(0.45·0.6, 반광처럼 보임)을 "그대로 두기"로 골랐다. 그래서 이번에는 유광 느낌을 두고 점만 다뤘다.
- 평가: 감독(Codex)이 좌우를 가린 그림으로 판정했다.

## 1. 평가 기준

1. 뒷벽 위쪽에 점처럼 맺힌 조명 반사가 없다.
2. 유광 느낌(방이 비치는 반사)이 남는다. 반광처럼 탁해지지 않는다.
3. 벽 색(1번 "같은 타일"), 줄눈, 모서리 깊이(2번 모서리 그늘)가 그대로다.
4. AI에 보내는 그림은 바뀌지 않는다.

## 2. 위치와 원인

- 편집 화면 3D 기본 시점(`defaultRoomView`)에서 **뒷벽 위쪽 가운데**에 둥근 밝은 점이 있다.
  - 올리브·검정·베이지 유광 벽에서 뚜렷하다.
  - 흰 벽은 거의 보이지 않는다.
- 원인은 **천장 조명(`realistic-lighting.ts` 천장 스포트라이트)의 직접 반사**다.
  - 벽의 직접광 반사를 끄면(`d0`) 사라진다.
  - 주변 환경 반사를 끄면(`i0`) 그대로다.
  - 유광 타일은 거칠기가 낮아(유광 0.24, 폴리싱 0.12) 천장 조명이 작고 밝게 맺힌다.
- 점 세기: `tests/editor-glare/spot.mjs`로 쟀다. d0보다 밝아진 L\*의 봉우리다.

| 방     | 지금 | r35  | r50 | s30  |
| ------ | ---- | ---- | --- | ---- |
| 올리브 | 26.9 | 9.8  | 4.1 | 10.9 |
| 검정   | 42.1 | 18.5 | 7.9 | 19.9 |
| 베이지 | 29.2 | 3.6  | 1.4 | 23.7 |
| 흰색   | 7.4  | 2.1  | 1.1 | 2.5  |

- 후보는 모두 벽에만 적용했다.
  - r35·r50: 천장 조명(직접광)에만 벽 거칠기를 0.35·0.5 이상으로 본다. 주변 반사는 타일 원래 거칠기다.
  - s30: 직접광 반사만 ×0.3이다. 점이 작아질 뿐 남아 평가에서 뺐다.
- 점이 아닌 나머지 벽의 변화는 평균 0.24 L\* 이하다.

## 3. 감독 가린 평가 (편집 화면 전체 + 뒷벽 위 확대, 8쌍)

- **r50 대 지금: 3승 0패 1무.** r35 대 지금도 3승 0패 1무다. 무승부 2쌍은 모두 흰 타일이다.
- 감독 판정: "검은 타일은 r50이 r35보다 반사 점을 깨끗이 줄인다". 고른 쪽에서 벽이 탁해지거나 모서리 깊이가 준 사례는 없었다.
- 결정: r50

## 4. 앱에 넣은 것 (`62bf25b`)

- `src/lib/room-viewer/surfaces.ts`
  - `LIVE_DIRECT_ROUGHNESS` 0.5
  - 셰이더 `lights_fragment_begin`(직접광) 앞: 벽(`sjnFaceAxis.y < .5`)의 거칠기를 `max(원래, sjnLiveDirectRoughness)`로 본다.
  - 바로 뒤에 원래 거칠기로 되돌린다. 그래서 주변 반사(`lights_fragment_maps`·`_end`)는 타일 원래 유광 그대로다.
  - uniform `sjnLiveDirectRoughness`: 기본 0.5, `setLiveLook(false)`이면 0이다. 0이면 `max(r, 0) = r`이라 지금과 같다.
- `src/lib/room-viewer/renderer.ts`
  - `export()`(AI 입력, 미리보기 캐시, 다운로드)와 `exportLayers()`(AI 합성·다듬기 층)는 그리는 동안 끄고, 끝나면 켠다.
  - 화면에 바로 그리는 `render()`만 켜진 채다.
- **바뀌는 곳(화면에 바로 그리는 3D):**
  - 편집 화면 3D(벽 구조가 있는 방의 편집 캔버스, `canvas-workspace.tsx`)
  - 방 편집 화면(`room-canvas-workspace.tsx`)
  - AI 변환 창의 3D 시점 미리보기(`ai-view-picker.tsx`)
- **바뀌지 않는 곳:**
  - AI에 보내는 그림과 층: 지금 main과 5장면 모두 바이트까지 같다. capture, input, joints, behind, soft, mask, 문장, grounding이다.
  - 디자인 미리보기 캐시(`room-design-preview.ts`), 렌더 스냅숏, 3D 다운로드: 모두 `export()`
  - 2D 편집 화면(2D 합성), 바닥(벽에만 적용)
  - 결정 B, 모서리 그늘(2번), 주변 반사
  - `DESIGN_RENDER_REVISION`은 올리지 않았다. 미리보기는 `export()`라 바뀌지 않기 때문이다.
- 앱 그림 = 시험 그림: 앱의 편집 화면 3D가 r50 시험 그림과 4방 모두 픽셀까지 같다.
