# 세면대 표준 모형과 기존 분석의 설치 근거

2026-09-13 변경. Qwen·DeepLab 모델 가중치를 교체하지 않았으며, 이 문서의 모형 검사는 AI 인식 정확도 평가와 별개다.

## 형태와 개수

`ReconstructionStandardOptions`의 `basinVariant`(벽걸이·기둥·하부장), `basinShape`(사각·곡면), `bowlCount`(1·2)를 독립적으로 표준 모형에 반영한다. 사각 기둥형과 곡면 벽걸이를 지원하고, 벽 설치 하부장은 바닥 받침을 생략한다. 볼에는 실제 안쪽으로 들어간 형상이 있고 수전은 별도 형상이다. 제품 전체 치수에는 수전 높이가 포함된다. 자동 실측 치수는 아니다.

새 하부장은 명시적인 1볼 기본값으로 시작한다. 넓다는 이유로 볼 두 개를 관측한 것으로 처리하지 않는다. `bowlCount`가 없는 기존 저장 모형은 과거 폭 기반 표현을 유지한다. 해당 제품을 수정할 때도 이전 표현의 개수를 명시해서 이어받으며 원래 자재 버전과 사진은 변경하지 않는다.

모형 생성과 실시간 렌더 캐시에 형태·볼 개수·설치 면을 포함한다. 현재 스냅샷의 투명 PNG와 실시간 화면 모두 같은 표준 모형 옵션을 사용한다. 새 옵션은 기존 fixture metadata의 교집합 타입을 통해 저장·복사·실행 취소에 포함되며 Supabase 검증에도 추가했다. 실제 Supabase 연결 검증은 수행하지 않았다.

## 기존 DeepLab 분석에서 얻는 근거

`basin-observations.ts`는 실제 세면대 분류 영역의 하단 윤곽을 직선·곡선에 맞춰 비교한다. 프레임에서 잘렸거나 영역이 작거나 윤곽이 불규칙하면 형태를 확정하지 않는다. 기둥 지지부가 이미 관측됐으면 그 폭을 이용해 볼 아래의 지지대 부분을 제외한다. 윤곽 범위·잔차·곡률을 보고서에 기록하며 출처는 `inferred`다. DeepLab이 사각/곡면이라는 세부 종류를 직접 출력했다고 표시하지 않는다.

하부장 위에 공간적으로 분리된 크기가 비슷한 강한 세면대 영역 두 개가 있을 때만 `separate-basin-components` 근거와 원 후보 ID 두 개를 기록한다. 하나의 넓은 영역, 작은 조각, 겹친 영역, 확인이 필요한 약한 후보는 두 볼의 근거가 되지 않는다. 모형 기본값과 관측값은 `provenance.shape`, `provenance.bowlCount`로 구분한다.

세그멘테이션 윤곽은 실제 물체의 정밀 윤곽과 다를 수 있고, 원근·수전·가림의 영향도 남는다. 해당 추정은 정답이나 제조 형태의 확정값이 아니다. 사진에서 볼 두 개가 보이더라도 분석기가 하나의 연결 영역으로 출력하면 현재 방식은 두 개라고 확정하지 않는다.

## 설치 벽과 높이

`geometrySource`로 방의 관측 경계에 맞춘 `room-boundaries`와 마감만 남기기 위한 `appearance-region`을 구분한다. 후자는 실제 천장·바닥 전체 범위나 설치 벽을 확정하지 못하므로 자동 설치 위치에 사용하지 않는다. 이전 이름이 `observed-*`인 영역도 같은 제한을 적용한다. 벽 색과 타일 반복은 계속 보존한다.

설비 관측은 삭제하지 않는다. 바닥과 떨어진 세면볼은 벽걸이 제안과 설치 벽·높이 확인 이유를 남긴다. 사용자가 설치 벽을 확인하면 위치를 수정할 수 있으며, 불완전한 마감 영역의 세로 비율을 방 높이로 곱하지 않는다. 벽걸이 세면대 하단 높이 650mm 등 수정 가능한 기본값과 `position: default`를 명시한다. 관측한 방 경계가 충분하거나 사용자가 공간 대응을 확인한 경우에만 그 대응을 이용한다.

자동 배치가 줄어드는 것 자체를 품질 향상으로 계산하지 않는다. 올바른 설비를 찾고 배치했는지, 잘못된 벽 확정을 피했는지, 보류와 사용자 수정량이 얼마나 늘었는지를 실제 사진 평가에서 따로 확인해야 한다.

- 사각 기둥·곡면 벽걸이·사각 벽걸이·곡면 1볼 하부장·사각 2볼 하부장·벽걸이 하부장 투명 PNG를 저장하고 직접 비교했다.

- 이 단위·브라우저 자료는 지정한 검증 형상이다. 사용자 네 사진과 별도 사진의 실제 새 추론 결과·처리 시간은 루트 통합 평가에서 기록한다. 여기서 실제 사진 인식 성공을 주장하지 않는다.
