# 자재 이미지 등록·표시 정책

상품 소개 이미지와 대표 이미지 설정을 제거했다. 제품은 **제품 이미지**만, 타일은 **타일 텍스처**만 올려 등록한다. 별도 대표 이미지 업로드·지정·추가 상품 소개 사진 입력은 없다.

## 목록에 사용할 사진

- 제품: 이름이 **정면**인 사진을 우선한다. 정면 사진이 없으면 등록 순서상 첫 제품 사진을 사용한다.
- 영문 `front`, `frontal`도 정면으로 처리한다. 앞뒤 공백·영문 대소문자는 무시한다. `정면 30도`처럼 다른 이름은 별도 각도로 유지한다.
- 타일: 첫 렌더링 텍스처를 사용한다.
- 같은 규칙을 자재 라이브러리 카드, 상세 보기 큰 이미지, 편집기 자재 목록, 자재 수량·금액의 작은 이미지에 공통 적용한다.
- 사진 이름을 바꾸거나 사진을 삭제하면 규칙에 따라 표시 이미지가 달라진다. 별도의 대표 이미지 선택 상태를 저장하지 않는다.

## 제품 각도 이름

사진마다 이름 입력과 **빠른 선택** 메뉴가 함께 보인다. 정면·왼쪽 사선·오른쪽 사선·왼쪽 측면·오른쪽 측면·위에서·뒤에서 중 선택할 수 있고 `왼쪽 25도`처럼 직접 입력할 수도 있다. 직접 입력한 이름을 메뉴의 고정 이름으로 강제로 바꾸지 않는다.

360° 제품 편집 창의 새 각도 이름과 이름 변경에도 같은 입력 방식을 사용한다. **이 각도 추가**는 새 사진을 만들고, **선택한 각도 수정**은 선택한 사진만 갱신한다. 자재 폼의 **자재 등록 / 새 버전 저장**이 최종 저장이다.

## 기존 자료

기존 자재 버전에 남아 있는 대표·상품 소개 이미지 ID는 읽을 수 있다. 배치 사진이나 타일 텍스처가 있는 새 버전을 저장할 때 이전 대표 설정을 저장 상태에서 정리한다. 배치 이미지가 없는 예전 자재는 기존 이미지를 표시할 수 있도록 호환한다.

새 제품 배치는 정면 우선 규칙으로 사진을 선택한다. 이미 공간에 배치된 제품의 `viewIndex`는 표시용 썸네일 정책 때문에 바꾸지 않는다. 기존 프로젝트의 불변 상품 버전과 사진도 그대로 유지한다. 각도 변경은 제품 속성의 사진 썸네일로 수행한다.

## 검증

`e2e/material-images.spec.ts`는 서로 다른 색의 실제 PNG를 올려 제품 정면 우선·첫 사진 대체·타일 텍스처 표시를 네 화면에서 픽셀로 확인한다. 별도 대표 이미지를 올리지 않고 등록하는 흐름과 빠른 선택/자유 입력도 검사한다. 두 번째 정면 사진을 새 제품에 적용하고, 사용자가 첫 사진으로 바꾼 기존 배치는 새로고침 후에도 유지되는지 확인한다. 이번 통합 실행은 14개 통과, 실제 AI opt-in 1개 건너뜀이다. 자세한 결과는 [360° 검증 기록](./product3d-validation.md)에 있다.

```powershell
npx playwright test --config playwright.product3d.config.ts
```

새 AI 모델을 호출하는 변경이 아니므로 기존 실제 메시 재생 검증을 사용하며 AI 실추론을 반복하지 않는다.
