# SMC 천장: 누르면 보이고, 조명은 켜고 끌 수 있게 — 결과 (2026-10-31)

편집 화면 도구줄의 **SMC 천장**을 누르면 천장이 보이고, 다시 누르면 사라진다. 가격에는 들어가지 않는다. 켜져 있으면 옆의 **조명**으로 패널과 빛을 함께 끈다.

**2026-11-01 바뀐 점(사용자 요청).** 사용자가 AI로 만든 그림 `public/ceiling/smc-ceiling.webp`를 천장 전체에 늘려 입힌다. 이 문서의 단색·`#ece7da` 설명은 그 전 기준이다.
- 그림을 읽지 못하면 같은 색의 단색 `#ecebe7`로 그린다. 그림은 페이지마다 한 번 읽고, 실패하면 다음 천장에서 다시 시도한다.
- 3D 천장 채움을 켬 0.8에서 0.6으로 낮췄다. 0.8은 천장이 바깥 배경 `#e8e8e4`과 거의 같아져(ΔE 0.45) 앞쪽 가장자리가 사라졌다. 0.6은 평균 `#d3d3ce`, ΔE 7.49다. 2D는 바꾸지 않았다(ΔE 약 2).
- 시험 전 비교: 그림과 `#ecebe7` 단색의 차이는 12개 조합에서 평균 ΔE 0.46~0.55로 눈에 보이지 않았다.

## 2. 처음 명세와 달라진 점

처음 명세는 "천장에 타일 깔기"였다. 사용자가 질문에 답하며 SMC 천장 옵션으로 바꿨다.
- 천장은 면(Surface)이 아니라 장면의 선택 항목 `ceiling: { kind: 'smc', light }`이다.
- 그래서 면 나누기, 면적, 사용량, 견적, 시공 설정, 적용 위치, 벽 밝기 기준을 건드리지 않는다.
- 자재 패널의 천장 탭도 만들지 않았다.

## 3. 코드에서 다르게 확인한 것

- 명세는 "위에서 내려다보는 시점이 지금 화면에 없다"고 했지만, **AI 입력 카메라에는 위에서 보는 시점이 있다**(`fluxOrbitView`, `tests/flux-orbit-view-browser.ts`의 top). 그대로 그리면 천장이 방을 가린다. 카메라가 천장보다 위면 숨긴다(`ceilingShown`).
- 2D 배경에는 조명 패널이 없다. 패널은 2D 천장 패스에서 새로 그린다.
- 375px 도구줄은 버튼이 늘면 넘친다(17px). 좁은 화면에서 줄바꿈되게 했다. 벽 구조 도구를 켰을 때도 같은 효과를 본다.
- 계획은 2D 어둡게 하기를 기존 노출 값에 곱한다고 했으나, 그러면 Before와 방 바깥 배경까지 어두워진다. 최종 출력에서 **After의 방 영역에만** 곱한다.

## 4. 쓰는 법

- 켜기·끄기: 가운데 도구줄의 SMC 천장(2D는 아이콘, 3D는 글자)
- 조명: 천장이 켜져 있을 때 옆의 조명 버튼
- 쓸 수 없는 때: 방 없는 옛 사진 장면, Before 편집, 읽기 전용, 비교 보기. 버튼이 꺼지고 이유를 툴팁에 보인다.
