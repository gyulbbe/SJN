## 결과를 보기 전에 고정한 판정 기준

1. **설치 벽:** 눈에 보이는 부착 면을 판단한다. 사진 좌우를 표준 공간의 물리 벽 축으로 바로 바꾸지 않는다. source-view 벽은 실측 벽 정답이 아니며 보이지 않는 벽은 unknown이다.
2. **상대 높이:** 각 사진 주석의 거울/선반/세면대/변기 순서와 지지 관계를 평가한다. 다른 카메라로 본 PNG의 y좌표를 직접 비교하거나 mm 실측 오차라고 하지 않는다.
3. **방향:** 관측 가능한 앞면·벽 부착·열린 창짝 방향만 판단한다. 열린 창짝을 방 벽으로, 가려진 후면을 접점으로 자동 해석하지 않는다.
4. **가림·잘림:** 앞뒤로 실제 존재하는 설비를 유지한다. 커튼·배관·반사를 추가 설비로 만들지 않는다. 화면 밖 제품의 크기·깊이는 관측값으로 확정하지 않는다.
5. **누락·표현:** 종류를 찾음, 보류, 실제 모형 생성, 형태 지원 불가를 나눈다. duplicate 수를 성공으로 세지 않으며 모든 실패를 표에 남긴다.
