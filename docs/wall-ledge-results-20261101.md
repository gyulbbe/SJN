# 젠다이: 벽에서 튀어나온 조적 구조 — 결과 (2026-11-01)

벽 구조 도구에서 홈뿐 아니라 방 쪽으로 튀어나온 젠다이도 만든다. 바닥부터 쌓은 조적 젠다이와 벽에 붙어 떠 있는 선반 모양을 모두 그린다.

## 1. 결정

| 항목 | 정한 것 | 누가 |
| --- | --- | --- |
| 고르는 곳 | 도구줄에서 먼저 고름 `[ 홈 | 젠다이 ]` | 사용자(추천안) |
| 놓는 높이 | 바닥형과 공중형. 바닥에서 0이면 바닥형 | 사용자(추천안) |
| 타일 | 벽 타일이 앞·옆·윗면으로 이어짐 | 사용자(추천안) |
| 견적 면적 | 실제 시공 면적. 조적 공사비는 넣지 않음 | 사용자(추천안) |
| 벽 모서리 | 젠다이는 벽 끝까지 붙음(홈은 10mm 여백 그대로) | 기본값(계획 승인) |
| 눌러서 놓기 | 바닥형, 폭 min(1200, 벽/2), 높이 min(900, 방 높이/2), 깊이 150 | 기본값(계획 승인) |
| 깊이 기억 | 홈과 젠다이를 따로 | 기본값(계획 승인) |
| 방 높이 변경 | 바닥에서의 높이 유지 | 기본값(계획 승인) |
| 면 음영 | 앞 0.86, 옆 0.72, 아래 0.6배로 어둡게, 윗면은 그대로 | 구현 중 결정(아래 3절) |

## 2. 쓰는 법

1. 가운데 도구줄에서 **벽 구조**를 켜고 **젠다이**를 고른다.
2. 왼쪽·정면·오른쪽 벽을 끌거나 누른다. 벽 아래 끝까지 끌면 바닥형, 벽 양 끝 10mm 안까지 끌면 그 끝에 붙는다.
3. 카드에서 깊이(벽에서 나온 길이)·왼쪽 끝에서·바닥에서·폭·높이를 고치고 Enter로 적용한다.
4. 놓인 젠다이는 눌러 고르고, 끌어 옮기고(바닥형은 좌우만), Delete로 지운다. 숫자로 고쳐도 홈으로 바뀌지 않는다.

## 3. 그리기

- 저장: `wallFeatures`의 새 kind `ledge`. `leftMm, bottomMm, widthMm, heightMm, depthMm`이고 `topMm`이 없다. 기존 kind와 저장 형식은 그대로이고 D1 스키마·SQL·API도 그대로다.
- 3D: 벽의 구멍은 홈과 같은 코드로 내고, 음수 깊이로 같은 상자를 방 쪽으로 낸다([wall-feature-geometry](../src/lib/room-viewer/wall-feature-geometry.ts)). 타일은 벽 좌표에서 펼쳐져 모서리를 돌아 이어진다.
- 그림자: 젠다이 조각만 그림자를 드리우고, 바닥형은 제품처럼 바닥 닿는 자리에 음영이 있다.
- **면 음영을 넣은 이유:** 조명이 방 가운데 위에 있어 그림자는 젠다이 뒤쪽으로 떨어지고, 앞면은 벽과 밝기가 같았다. 화면에서 줄눈이 조금 어긋날 뿐 어두운 타일에서는 젠다이가 거의 보이지 않았다. 그래서 면마다 고정된 비율로 타일을 어둡게 한다. 물리 계산이 아니다.
- 벽이 숨겨지면 그 벽의 젠다이도 함께 숨는다. 다른 벽에 붙은 끝면은 그 벽이 숨겨졌을 때만 보인다(겹쳐 깜박이지 않게).
- 젠다이가 있으면 편집 화면은 다른 벽 구조처럼 3D다. 2D에서는 첫 젠다이를 그리는 윤곽만 보인다.
- 젠다이가 없는 장면은 렌더 결과가 같아 `ROOM_VIEWER_RENDERER_REVISION`을 올리지 않았다.

## 4. 면적

예: 2.4m 방 정면 벽, 폭 900·높이 800·깊이 150mm, 바닥형, 벽 가운데.

| 항목 | 면적 |
| --- | --- |
| 앞면 | 0.72㎡(가려진 벽과 상쇄) |
| 옆면 2개 | +0.24㎡ |
| 윗면 | +0.135㎡ |
| **벽 타일 변화** | **+0.375㎡** |
| **바닥 타일 변화** | **−0.135㎡** |

- 공중형은 아랫면을 더하고 바닥은 그대로다.
- 벽 끝에 붙으면 그 끝면은 시공하지 않으므로 빼고, 맞닿은 옆벽에서 가려진 넓이를 뺀다.
- 사용량·견적은 같은 면적 함수를 쓴다([room-surface-areas](../src/lib/room-surface-areas.ts)). 조적 공사비는 없다.

## 5. 요청 수 (`e2e/wall-feature-drawing.spec.ts`)

- 끌기·카드 입력·이동 중 프로젝트 요청 0
- 적용 1번, 이동 1번: 각각 저장 1번
- 저장 API·SQL을 바꾸지 않아 D1 쿼리 수 측정은 해당 없음

## 7. 한계

- 제품과의 충돌은 막지 않는다. 변기를 젠다이에 겹쳐 놓을 수 있고, "벽에 붙이기"는 벽을 기준으로 한다. 젠다이 위에 제품을 올리는 기능도 없다.
- ㄱ자처럼 옆벽 젠다이끼리 잇거나, 젠다이 안에 홈을 내는 것은 겹침으로 거절한다.
- 상판 자재를 따로 고르지 않는다.
- 끌어서 크기를 바꾸는 손잡이는 없다. 크기는 숫자로 고친다.
- 윤곽을 끄는 동안의 미리보기는 벽면 위에 그린다. 놓은 뒤에는 앞면에 그린다.
