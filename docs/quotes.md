# 이전 견적 기능

2026-09-07부터 견적서 작성·인쇄/PDF 화면을 제거하고 **우측 자재 수량·금액 패널**로 교체했습니다. 사용 방법과 계산·검증 결과는 [자재 수량·금액](material-usage.md)을 참고하세요.

기존 프로젝트의 `quote` 원본은 보관합니다. 불변 상품 버전·판매 단위·연결 면/제품이 정확히 맞는 단가와 타일 수동 면적·구매 수량만 새 상태로 이관하며, 제품 개수는 After의 실제 배치에서 다시 계산합니다. 세금·할인·추가 항목·자동 여유분과 기존 합계는 새 합계에 사용하지 않습니다. 기존 견적 작성·인쇄 API를 새 기능에서 호출하지 않습니다.
