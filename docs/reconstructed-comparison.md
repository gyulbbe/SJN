# 사진으로 재구성하는 Before / After

기존 공간 사진을 그대로 Before에 겹치는 대신, 사진 속 타일과 기구를 공간미리의 방 안에 다시 배치합니다. After는 같은 치수·카메라의 빈 방에서 시작합니다. 촬영 각도가 다른 사진과 렌더링을 직접 비교할 때 생기는 차이를 줄이고, 기존 배치와 새 디자인을 같은 틀에서 확인하기 위한 기능입니다.

## 시작하고 비교하기

1. 홈의 **사진으로 비교 공간 만들기**에서 기존 공간 사진 한 장과 **가로·깊이·높이**를 입력합니다. 기본값은 각각 **2.4m**, 가로·깊이는 **0.5–20m**, 높이는 **1–6m**입니다. JPG·PNG·WebP, 파일당 25MB·40MP 제한을 적용하며 원본을 보존합니다.
2. **자동 초안 만들기**를 누릅니다. 사진은 브라우저의 Worker 안에서 분석합니다. 분석이 어려운 사진은 **분석 없이 직접 구성**으로 시작할 수 있습니다. 분석에 실패하면 입력 사진과 치수를 유지한 채 재시도할 수 있습니다. 취소한 분석의 늦은 결과는 적용하지 않습니다.
3. 생성 직후 **빈 After 편집 화면**이 열립니다. 새 자재와 제품을 바로 배치할 수 있습니다. 사진에서 재구성한 Before는 별도로 저장되고 상단 Before 버튼으로 확인합니다. 보정이 필요하면 **기존 공간 수정**을 누릅니다. **초안 보정**에서 누락된 모형을 추가하거나 후보 배치를 확인하고, 선택한 면·제품의 속성에서 색·규격·위치를 조정합니다. **등록 자재 보기**에서 직접 등록한 타일과 제품도 사용할 수 있습니다.
4. 사진에 보이는 바닥은 방 전체 깊이와 다를 수 있습니다. 자동 깊이는 임시로 뒤쪽 **65%**에 대응시키는 추정이며, 근거가 부족한 기구는 확인 필요 또는 미배치 후보로 남습니다. 수동 사진 면 지정 기능은 제공하지 않습니다.
5. Before를 수정했다면 상단 **After** 또는 **After 꾸미기로 돌아가기**를 누릅니다. After의 디자인을 이어서 꾸밀 수 있으며, 두 장면은 서로 덮어쓰지 않습니다. 화면 전환은 확인 상태나 편집 revision을 변경하지 않습니다. Before 확인은 After 작업의 필수 단계가 아닙니다.
6. 상단 **Before / After**, 비교 슬라이더, 좌우 비교 다운로드로 확인합니다. **참고 사진 보기**는 업로드한 원본을 별도로 보여 줍니다. Before 편집 중에도 상단 비교 버튼을 사용할 수 있습니다. After로 돌아오면 내보내기를 사용할 수 있고, 자재 수량·금액 패널은 Before를 볼 때도 현재 시안의 After를 집계합니다.

**기본 공간으로 시작**과 **새 프로젝트**는 사진 없이 Before·After 모두 빈 상태에서 시작하고 After를 편집합니다. 이때 Before는 초기 빈 방 배경으로 유지됩니다. 홈에서 사진을 끌어 놓으면 사진이 선택된 비교 생성창이 열립니다. 이전 사진 합성이 필요한 경우 홈의 **기존 사진 위에 직접 편집하기 → 사진 위에 직접 편집**을 사용합니다. 기존 저장 프로젝트는 자동 변환하거나 초기화하지 않습니다.

## 원본 특징을 우선하는 재분석

- 비교 공간의 자동 초안은 전체 사진, 좌우 반전 사진, 분류가 모호한 물체의 확대 영역(최대 6곳)을 브라우저에서 다시 분석합니다. 기존 사진 편집의 벽/바닥 자동 적용은 이전 단일 분석 경로를 유지합니다. 처리 시간을 줄이기 위해 기구를 임의로 확정하지 않습니다.
- 서로 연결된 세면볼·상판·수납장을 세면대 하부장으로 묶습니다. 작은 원통형 물체나 전체/확대 분석이 불일치하는 후보는 확인 필요로 남깁니다. 반전 분석은 놓친 거울 후보를 찾는 보조 근거이며, 내부 점수를 인식 정확도 백분율로 표시하지 않습니다.
- 벽의 꺾임을 확정하지 못해도 관측된 벽 색을 보존합니다. 밝거나 어두운 줄눈의 반복, 긴 경계선, 하부 색의 연속성이 있을 때 상부 도장과 하부 타일을 독립된 높이 구간으로 만듭니다. 가구에 가려진 노출 바닥의 끝을 방 전체의 끝으로 보지 않도록 보정하며, 사진에 보이는 가로 구간도 저장합니다.
- 변기·세면대장 모형은 폭·높이·깊이를 공통 카메라에서 한 번 투영합니다. 바닥의 보이는 접점을 부피 중심으로 보정하고 발자국이 방 밖으로 나가지 않게 맞춥니다. 세면대장은 상판·볼·수납장을 나누며, 설치 방향과 규격은 속성에서 바꿀 수 있습니다. 자동 규격은 사진 단서에 기반한 추정입니다.
- 창·거울은 관측된 프레임·유리·반사 영역을 원본 벽의 방향으로 정면 보정한 뒤 공통 방에 투영합니다. 원본과 파생 자산을 함께 보존하며 이동·규격 수정·재진입 때 재사용합니다. 반사는 사진 촬영 당시의 모습이므로 새 배치에 맞춰 물리적으로 바뀌지는 않습니다. 사진 디테일의 색은 선택 자재 색감 도구로 조정합니다.

기존 재구성 프로젝트는 **기존 공간 수정 → 초안 보정 → 사진 다시 분석 → Before 다시 만들기**로 새 분석을 적용할 수 있습니다. 현재 Before는 한 번의 실행 취소로 복구할 수 있고, After 디자인과 자재 수량·금액은 유지합니다. 재분석 취소 또는 오래된 결과는 현재 장면을 바꾸지 않습니다.

이 기능은 사진을 참고하는 편집 가능한 재구성입니다. 원본과 같은 실사 장면, 정확한 제품 식별, 장식품·러그·가려진 물체의 완전 복원까지 보장하지 않습니다. 저해상도 사진의 없는 디테일을 새로 만들어 원본처럼 표시하지 않습니다. 원본 사진은 별도로 확인할 수 있습니다.

## 자동 초안이 표현하는 것

- 앱에 포함된 **DeepLabV3 MobileNetV2 ADE20K** 모델을 사용해 벽·바닥과 변기·세면대·욕조·거울·문·창 후보를 찾습니다. 사진을 외부 AI 서비스로 전송하지 않으며, 모델의 내부 점수를 인식 정확도 백분율로 표시하지 않습니다.
- 벽·바닥의 대표색은 분할된 면에서 추출합니다. 물체·강한 그림자·반사 영향을 줄이고, 원근을 정리한 면에서 일관된 줄눈 반복을 찾을 때만 타일 규격을 추정합니다. 반복을 찾지 못한 면은 줄눈 없는 대표색으로 시작합니다.
- 타일 수동 설정의 초기 규격은 바닥 **300×300mm**, 벽 **300×600mm**입니다. 자동 규격을 찾지 못했을 때 줄눈은 **0mm**이며, 속성에서 줄눈을 설정할 수 있습니다. 검출한 격자의 줄눈 초기값은 **2mm**입니다. 이 수치들은 모두 추정 또는 사용자 설정값입니다.
- 변기·세면대·세면대 하부장·욕조는 직접 제작한 단순 Three.js 도형을 방의 카메라에 맞춰 렌더한 투명 이미지로 표현합니다. 창·거울은 관측된 원본 이미지를 정면 보정해 설치 벽에 투영하며, 원본 영역이 없거나 수동 추가한 경우 직접 그린 평면 모형을 사용합니다. 문은 직접 그린 평면 모형을 사용합니다. 종류·색·가로·높이·깊이·설치 면·상대 위치와 배율을 수정할 수 있습니다.
- 재구성 모형에는 실제 상품명·제조사·가격을 붙이지 않습니다. 내부 자재 버전으로 저장하지만 일반 상품 목록과 새 After에는 자동으로 노출하거나 배치하지 않습니다. 등록 제품으로 바꾸려면 Before에서 해당 모형을 선택하고 등록한 제품을 적용합니다.

사진에 보이지 않는 면은 중립색으로 남습니다. 인접한 같은 종류의 물체가 하나로 인식되거나 작은 물체가 누락될 수 있으므로, 초안은 원본과 비교해 보정해야 합니다. 숨겨진 공간, 실제 제품 형상, 사진의 조명이나 정확한 실측 카메라를 복원하는 기능은 아닙니다. 방은 직육면체를 기준으로 하며 복잡한 평면을 자동 복원하지 않습니다.

## 같은 구도와 자재 수량·금액

Before와 After는 방 치수·카메라 버전·화면 비율을 공유합니다. 확대·이동·비교 슬라이더는 장면 편집과 분리되어 두 장면을 같은 위치에서 보여 줍니다. 타일·제품·색감은 각각의 장면에 독립적으로 저장합니다. 이전 프로젝트의 보호 영역·복원 배경은 계속 읽어 합성하지만 새로 그리는 도구는 제공하지 않습니다.

**공간 크기** 변경은 Before와 모든 시안에 함께 적용됩니다. 초기화되는 수동 경계·보호·가림·복원 배경은 Before와 After를 구분해 안내하며, 확인 후에만 적용합니다. **공간 크기 → 크기 변경 직전 전체 복원**으로 전체 장면·자재 수량·금액·개별 이력과 공유 치수를 함께 복구합니다. 일반 실행 취소는 현재 시안 또는 Before에서만 동작하고 치수 변경 경계를 넘지 않습니다. 각 제품의 설치 면 내 상대 위치와 배율은 유지합니다.

**자재 수량·금액은 After의 자재와 제품만 집계합니다.** Before 초안 모형이나 기존 타일은 구매 수량에 섞이지 않습니다. Before를 보정해도 After 자재 수량·금액의 수량·단가는 바뀌지 않습니다. 공동 치수 변경 시 After의 연결된 면적·자동 수량은 갱신하고, 직접 입력한 면적·수량·단가는 유지합니다. 자재 수량·금액 계산의 자세한 기준은 [자재 수량·금액 안내](material-usage.md)를 참고하세요.

다운로드는 화면과 같은 렌더러에서 합성한 결과를 사용합니다. PNG/JPG의 After 또는 좌우 비교를 지원하며, 출력 전체의 긴 변은 최대 4096px와 원본·GPU 한도 안에서 제한됩니다. 편집 핸들은 출력에 포함되지 않습니다.

## 문서와 저장 계약

프로젝트 **v3**의 `shared.comparison`은 공통 Before와 참고 사진, 방 설정, 카메라 버전 및 보정 근거를 보관합니다. After는 활성 시안의 `scene`에서 조회합니다. `RenderSnapshot.beforeScene`은 실제 재구성 Before를 공통 렌더러에 전달합니다. 재구성 정보가 없는 사진 프로젝트는 기존 원본/편집 비교 의미를 유지합니다.

Before 실행 취소는 `shared.beforeHistory`, 시안 실행 취소는 각 시안의 `{ scene, materialUsage, quote? }` 기록에 보관하며 각각 최근 50개를 유지합니다. 선택·줌·편집 대상·비교 전환은 장면 revision을 올리지 않습니다.

v1/v2는 읽을 때만 메모리에서 v3로 정리하고 기존 저장 문서를 변경하지 않습니다. 현재 공간과 호환되는 이력은 각 기록으로 나누며, 이전 치수의 기록은 별도 프로젝트 복원용으로 보존합니다. 자산 정리는 모든 시안·Before·개별 이력·전체 복원 백업과 참고 사진을 확인합니다. 일반 자재와 개인 복제·수정 자재는 내부 재구성 캐시 정리에서 제외합니다.

## 검증과 제한

상태·저장 테스트는 Before/After 편집 분리, 자재 수량·금액 보존, 전체 시안 치수 변경과 전체 복원, 비교 전환의 revision 불변, v1/v2 읽기와 v3 조건부 저장, 복제 이후 공유 이미지·참고 사진·이력 보존을 확인합니다. 브라우저 실행 결과와 실제 확인한 장면·미실행 항목은 [다중 시안 검증](designs-verification.md)과 [기존 검증 기록](verification.md)을 기준으로 확인하세요. 자산과 모델의 출처는 [자산 안내](assets.md)에 기록합니다.

기구는 편집 가능한 2D 레이어로 배치됩니다. 단순 모형을 만들 때 사용하는 Three.js 도형은 임의의 사용자 3D 모델 업로드 기능을 의미하지 않습니다. 제품 이동에 따른 숨은 면의 모양·반사·조명을 물리적으로 재계산하지 않으며, 사진과 정확히 같은 외형이나 실제 설치 가능성을 보장하지 않습니다.
