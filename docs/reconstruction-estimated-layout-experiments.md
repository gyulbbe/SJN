# 추정 배치의 기본 동작과 독립 실험

이 문서는 `buildEstimatedCandidatePipeline`의 채택한 기본 동작과 미채택 실험을 구분한다. 실제 사진 재현 품질 전체가 통과했다는 뜻은 아니다.

## 현재 기본값

- `photoRelationPolicy: checked`: 원래 모델 관계는 보존한다. 사진의 두 경계 상자가 완전히 분리되고 분명히 반대인 leftOf/rightOf/above/below만 배치 점수에서 제외한다. 겹치거나 가까운 영역, 깊이·지지·접합 관계는 이 검사로 변경하지 않는다.
- `assemblyBoundsPolicy: combined`: 실제 supportedBy 관계로 이미 검증한 세면볼·상판 조합만 두 관측 영역의 합집합과 비교한다. 원래 후보 경계는 그대로 보존하고 파생 범위는 `assemblies[].observationBounds`에 기록한다. 모순된 지지 영역은 held로 기록하고 원래 부모 범위를 유지한다.
- `cameraSearch: compact`: 기존 6개 카메라 가설과 유효한 strict 관측 시점을 유지한다.
- `cameraDirectionEvidence`는 기본적으로 사용하지 않는다. 이 필드가 명시적으로 제공된 실험만 관측 방향·화각 가설을 추가한다.
- `depthWallEvidence`가 제공되면 독립 사진 해시·크기·평면 유효성을 검사한다. 다른 후보 영역을 제외한 주변 표본에서 벽 방향만 약한 근거로 사용한다. strict 카메라의 원점/거리 보류를 해제하지 않는다.
- 검색은 기존 점수순 후보 36개, beam 8개를 유지한다. 실패한 wall/yaw quota 옵션과 프로덕션 분기는 제거했다.

실험 대조용 `raw-experiment`와 `parent-only-experiment`는 이전 동작 재생용이다. 제품 편집 기본값으로 사용하지 않는다.

## 관측 방향·화각 실험은 기본 채택하지 않음

`estimated-camera-directions.ts`는 유효한 바닥과 평행 벽 방향으로 quaternion을 만들고, 중앙 주점·정사각 픽셀 조건을 만족하는 추정 intrinsics에서 화각을 가져온다. 카메라의 위치는 기존 가설의 위치를 그대로 재사용하며 깊이 모델의 미터 거리로 방 크기나 카메라 원점을 맞추지 않는다. 원래 strict 보류 이유와 6개 기본 가설도 보존한다.

실제 pc01에서 세면대와 거울이 뒤벽에서 왼쪽 벽으로 이동했지만 87.87°의 추정 광각 때문에 설비가 작아지고 욕조 방향과 유리 크기는 여전히 부정확했다. 픽셀 손실은 1.346→1.500으로 커졌는데 벽 prior 감소로 총점은 낮아졌다. 실제 출력이 충분히 개선되지 않았으므로 기본 활성화하지 않는다. remote01은 기존 가설을 유지했고 추가06은 유효한 바닥 방향이 없어 보류했다.

## 실제 검증에서 구분한 결과

- 최신 15장 실제 관측에서 사진 방향 관계 7개를 격리했다. 점수의 잘못된 상수 벌점은 줄었지만 최종 배치 15장은 같았다. 이 수정을 시각 품질 개선으로 보고하지 않는다.
- 추가06의 세면볼·상판 조합은 부모 경계만 비교하던 문제를 고쳤다. 실제 렌더에서 뒤벽 쪽으로 상판이 들어왔지만 위치 잘림·캐비닛 방향·지지판 미복원은 남았다.
- 샤워 호스와 선반 충돌을 단순 AABB의 빈 공간 때문이라고 추측했으나 실제 삼각형 교차가 확인됐다. 이 사례에서 충돌 검사를 완화하지 않았다.
- wall/yaw quota 검색은 별도 3장 대조에서 pc01 배치를 바꾸지 못했고 나머지 두 사진은 점수가 악화됐다. 실패한 실험으로 분류하고 프로덕션에서 제거했다. 동결 소스와 결과는 보존했다.
