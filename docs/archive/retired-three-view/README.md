# 교체된 AI 세 방향 기능의 보관본

2026-09-12 360° 제품 편집기로 교체하면서 실행 경로에서 제외한 원본 소스와 검증 코드입니다. 사용자의 기존 저장 이미지나 모델 캐시는 이 폴더에 해당하지 않으며 삭제하지 않았습니다.

자동 승인 검토가 미추적 소스·테스트 일괄 삭제를 거절하여, 원문을 변경하지 않고 복원 가능한 보관본으로 이동했습니다. `.txt` 확장자는 현재 앱 빌드와 테스트 검색에서 제외하기 위한 것입니다. `manifest.json`의 원래 경로와 SHA-256으로 복원 및 확인할 수 있습니다. 경로가 이동했으므로 보관된 테스트는 그대로 실행하지 말고 당시 구현과 함께 복원해야 합니다.

재사용 가능한 형상 추론·표면 정밀화·모델 캐시 검사는 현재 `product3d` 소스와 테스트로 이전했습니다. 현재 기능의 검증은 [360° 편집기 문서](../../product3d-editor.md)를 참고하세요.
