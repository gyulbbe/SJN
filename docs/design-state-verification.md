# 다중 시안 상태·이력 검증

현재 시안 생성·복제 한도는 **5개**이며 비교도 **5개**다. 이전 10개 한도에서의 측정·시험 기록은 아래에 보존했다. [5개 한도 변경과 기존 자료 호환](five-design-limit.md) 참고.

검증 일시: 2026-09-07 (로컬 Windows, Node + Vitest)

## 저장 모델

- 새 문서는 `schemaVersion: 3`이며 최상위 `scene`, `quote`, `history` 별칭을 저장하지 않는다.
- `shared.baseline`과 선택적인 `shared.comparison`이 공통 기준 공간과 Before를 보관한다. `shared.beforeHistory`는 Before만 실행 취소한다.
- 각 시안은 독립적인 `scene`, `quote`, `history`, `revision`을 가진다. 이력 한 단위는 `{ scene, quote? }`이고 최근 50개를 유지한다.
- 시안 0개는 허용한다. 이때 기준 공간은 읽기 전용으로 보여 주며 자재·제품·견적 편집을 기준 공간에 기록하지 않는다.
- 생성·복제 한도는 중앙 명령에서 최대 10개, 비교 선택은 최대 5개로 검사한다. 연속 호출도 매번 최신 상태를 확인한다.

## 복제와 기존 문서

- 시안 복제는 진행 중인 조작을 확정한 최신 상태를 복사한다. 제품·면 ID와 견적 ID/번호/원본 면 참조를 새로 만들고 자산·자재 버전 ID는 공유한다.
- 수동 수량, 단가, 할인, 고객, 메모는 복사한다. 이미 자재 구성과 달라진 견적은 복제해도 동기화된 것처럼 표시하지 않는다.
- v1/v2 변환은 원본을 변경하거나 저장하지 않는 순수 변환이다. 재진입해도 동일한 시안 ID를 생성하며 기존 revision과 날짜를 유지한다.
- 현재 공간 좌표계와 호환되는 연속 이력만 시안/Before 이력으로 나눈다. Before만 바뀐 기록은 시안 실행 취소에 넣지 않는다.
- 호환되지 않는 기록을 포함한 기존 전체 이력은 `shared.legacyHistory`에 보존한다. 선택한 이전 기록은 별도 프로젝트로 복원할 수 있다.
- 자산 탐색은 현재 시안, 시안 이력, Before 이력, 이전 기록, 전체 공간 복원 백업을 모두 포함한다.

## 공통 크기 변경

- 크기 변경은 기준 공간, Before, 모든 시안과 연결 견적에 함께 적용한다. 시안과 Before의 일반 실행 취소는 새 치수 범위에서 시작한다.
- `roomHistory`에는 최근 크기 변경 한 번의 전체 작업 공간만 보관하며 `past` 또는 `future` 한 방향만 존재한다. 백업 안에 또 다른 `roomHistory`를 중첩하지 않는다.
- 전체 복원은 치수 변경 직전의 모든 장면·견적·마스크·개별 이력을 정확히 되돌린다. 변경 후 시안 생성/삭제도 함께 되돌린다. 복원 시점의 최신 작업 공간은 전체 다시 실행용으로 보관한다.
- 선택·줌·비교 선택 변경은 전체 다시 실행을 지우지 않는다. 새로운 편집은 전체 다시 실행을 지운다.
- 데이터 내용은 백업과 일치하게 복원하되 revision은 단조 증가한다. 삭제 후 같은 시안 ID가 복원되어도 과거 revision을 다시 쓰지 않아 오래된 미리보기/출력 응답과 혼동되지 않는다.

## 저장 응답과 진행 중인 조작

- 이름 변경, 견적 변경, 일반 장면/Before 명령은 남아 있는 조작 초안을 먼저 확정한다.
- 저장 응답은 현재 문서의 장면이나 선택 설정을 덮어쓰지 않는다. 저장 중 선택한 다른 시안, 비교 목록, 확대·이동은 유지하며 후속 저장이 필요하면 `dirty`를 유지한다.
- 이미 적용한 저장 응답보다 낮은 `storageRevision` 응답은 무시한다.
