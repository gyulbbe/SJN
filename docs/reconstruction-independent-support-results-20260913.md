# 설치 의미와 기둥 하단의 독립 연결

원래 사진→Before 개선 목표는 계속 진행 중이다. 이번 변경은 카메라가 미확정이어도 같은 설비의 설치 근거를 유지하고, 세면볼 아래쪽을 기둥의 바닥 접점으로 오용하는 경로를 수정한다. 자동 재구성 전체 품질 완료나 후보 엔진의 기본 채택을 의미하지 않는다.

## 실제 앱에 연결한 변경

- `candidate-pipeline.ts`는 같은 제품에 대한 `inspectObservedInstallation`을 촬영 카메라·수동 위치 존재와 독립적으로 실행한다. 미정인 설치 방식·지지 형태만 보완한다. 반사·종류/설치 충돌·유일한 대응 검사는 유지한다. 깊이 자료에서 설치 벽을 판단하는 경로는 유효한 카메라가 있을 때만 실행한다.
- `observed-support-contact.ts`는 같은 사진 해시·후보 대응·연속 지지대·하단 범위·반사/가림/다른 제품 혼입을 검증한다. 이 검사에는 방 좌표나 카메라를 입력하지 않으므로 바닥 투영이 성공했다는 이유로 지지점이 승인되지 않는다.
- `source-camera.ts`는 독립 지지점 입력을 별도로 받고 `supportEvidence`에 근거를 보존한다. 원래 모델의 anchor나 세면볼 bbox를 늘려 쓰지 않는다. 기둥형에 명시적인 모델 접점 또는 검증된 지지대 하단이 없으면 볼 bbox 하단을 바닥 접점으로 대체하지 않는다.
- Lab의 실제 파일 해시·이전 보고서의 동일 입력 확인을 거친 경로가 새 접점 검사에 사진 지문을 공급한다. 후보 엔진 revision은 `structured-scene-v10-independent-support-1`이다. 모델·프롬프트·대형 모델 다운로드 정책은 변경하지 않는다.
- 관측 목록에 독립 설치 판정과 지지점 근거를 표시한다. 이미 독립적으로 판단한 설치 방식·기둥형은 위치 편집의 기본값에서 활용한다. 원래 판단/사용자 보정값은 별도로 유지하며 사용자가 지정한 위치에는 지지점 자동 배치 출처를 붙이지 않는다.

지지점은 DeepLab 기둥 윤곽 하단 추정이다. 이를 바닥상의 모형 기준 위치로 사용하는 가정은 실제 접지 면 중심·제품 중심의 측정과 다르다. 기본 모형의 방향과 규격, 공간 기하가 잘못되면 별도 모형 검증에서 보류한다. 위치를 강제로 이동하거나 규격을 축소하지 않는다. 역투영 후 같은 점의 재투영 잔차도 사진 재현 정확도로 보고하지 않는다.

## 실제 저장 관측의 결과

[네 사진 설치 분리 재생](reconstruction-camera-support-separation-20260913.md)은 입력·원관측·카메라를 고정한 전후 검사다. 새 모델 실행이 아니다. 일반 후보 배치는 0/0/0/1, 깊이 실험은 0/0/0/3으로 유지됐으며 기존 계획 자체도 동일했다. 설치 의미의 보완을 배치 증가로 세지 않는다.

user03의 기둥 끝점은 동일한 연결 세면대 관측과 대응해 지지점 검사에 승인됐다. 미선택 카메라 가설 두 개의 후단에서는 이제 표준 모형 범위 검사까지 진행하지만, 기본 방향·600×800×480mm 모형이 왼쪽으로 각각 약45.54/46.10mm 넘쳐 보류됐다. 이는 다음 방향/규격 확인이 필요하다는 근거이지 카메라 가설을 자동 채택할 근거가 아니다.

원관측·기존 보고서·불변 자재 버전은 유지한다. 새 접점 자료는 일반 자재 가격이나 견적 수량에 들어가지 않는다. 이 변경은 단일 사진의 숨은 면·정밀 형태·실측 치수를 복원하지 않는다.

## 검증 기록

- 신규 접점 순수 검사40개, 새 후보 통합 검사6개. 반사·잘림·사진 불일치·유일 대응·지지 연속성, 원관측 불변·카메라 보류·명시 anchor 보존·수동 위치와 기본 규격 출처를 확인한다.
- 기존 관측 재사용 시험의 기둥 사례는 동일 사진 지문을 전달하도록 갱신했다. 기존 명시 접점과 다른 설비 카메라 배치 검사는 유지한다.
- 전체 ESLint·타입·Vitest **98파일1,208개** 통과. Next.js53.223초→vinext20.481초 순차 빌드 exit0. [원 로그](../test-results/reconstruction-independent-support-final-20260913/checks/checks.json).
- 실제 user03의 기존 관측으로 현재 Lab 보정→프로젝트 저장→새로고침→After undo/redo→시안 복사→PNG 전체 회귀1개가33.6초에 통과했다. [검증](../test-results/reconstruction-independent-support-final-20260913/e2e/reconstruction-lab-four-ph-f7fb6--저장-reload-undo-redo-시안-PNG/verification.json). 새 모델 실행과 사람의 최소 보정 시험이 아니다.
- 각 미선택 카메라에서 위치·규격을 고정하고 사용자 왼쪽벽 확인 가정만 넣으면 yaw0→90으로 벽 침범은0, 표준 세면대1개가 실제 렌더된다. [비교 PNG](../test-results/reconstruction-support-contact-wall-render-20260913/renders/comparison.html). 원사진의 각형 지지대와 기본 원형 기둥, 다른 설비 누락은 남는다. 볼 bbox와 전체 모형의 영역오차도 개선되지 않아 사진 재현 성공으로 세지 않는다.

관련 증거는 개인 사진을 공개하지 않는 ignored `test-results/reconstruction-support-contact-inspection-20260913/` 및 `test-results/reconstruction-camera-path-audit-20260913/after-installation-separation-final/`에 있다.


실제 Lab의 새 지지점 안내·위치만 보정 경로도 [브라우저 검사](../test-results/reconstruction-lab-support-contact-20260913/verification.json)에서 통과했다. 보존된 user03 모델의 floor/pedestal은 원래 알려져 있으므로 독립 설치 배너가0개인 것이 맞고, unknown→floor 개선으로 세지 않는다. 새 지지점 안내는 accepted이며 u/v만 입력한 뒤 사각 기둥형1개가 생성됐다. 600×800×480mm는 default 출처를 유지했고 원문·model/automaticUnderstanding·미확정 wall은 그대로다.
